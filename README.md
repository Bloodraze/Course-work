# Bloodraze — сайт музыкальной группы

Учебный проект: многостраничный сайт вымышленной музыкальной группы **Bloodraze**.  
Проект реализует только **фронтенд**: интерфейс, навигацию, адаптивную вёрстку и клиентскую логику. Реальный бэкенд, оплата и авторизация не предполагаются.

## О проекте

Сайт создан в рамках курсовой работы и представляет собой концептуальный веб-сайт музыкальной группы. Он включает страницы с информацией о группе, участниках, истории, предстоящих концертах, продаже билетов и мерча, а также личный кабинет и политику конфиденциальности.

Все участники, биографии, концерты, товары и цены являются вымышленными и используются исключительно в учебных целях.

## Ограничения

Проект реализует только клиентскую часть. Корзина, заказы, профиль и билеты работают в демонстрационном режиме и не сохраняют данные на сервере.

## Функциональность

- Главная страница с анонсами группы, релизов и ближайших событий
- Страница «О группе» с историей коллектива
- Страница участников с фотографиями, ролями и краткими биографиями
- Раздел концертов с расписанием, городами, площадками и статусами событий
- Страница билетов с выбором концерта, типа билета и количества мест
- Каталог мерча: футболки, худи, аксессуары, виниловые пластинки и другие товары
- Карточки товаров с ценой, описанием, размерами и кнопкой добавления в корзину
- Корзина и оформление заказа в демонстрационном режиме
- Личный кабинет: профиль пользователя, история заказов и сохранённые билеты
- Форма обратной связи и подписка на новости группы
- Страница политики конфиденциальности
- Адаптивная вёрстка для мобильных устройств, планшетов и десктопа
- Навигация по всем разделам сайта

## Установка и запуск

1. Клонируйте репозиторий:

```bash
git clone https://github.com/Bloodraze/Course-work.git
cd Course-work
```

### Запуск без Live Server

Откройте файл `index.html` в браузере одним из способов:

```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

Либо запустите проект через расширение **Live Server** в Visual Studio Code:

1. Установите расширение **Live Server**
2. Откройте файл `index.html`
3. Нажмите **Go Live** в нижней части окна VS Code

Сайт откроется в браузере по локальному адресу, например:

```text
http://127.0.0.1:5500
```

## Дизайн

Визуальный стиль сайта ориентирован на эстетику рок- или метал-группы: тёмная цветовая палитра, выразительная типографика, контрастные акценты, атмосферные изображения и динамичная подача контента.

Основные элементы интерфейса:

- Тёмный фон и яркие акцентные цвета
- Крупные заголовки и выразительные шрифты
- Карточки участников, концертов и товаров
- Адаптивное меню навигации
- Кнопки покупки билетов и добавления товаров в корзину
